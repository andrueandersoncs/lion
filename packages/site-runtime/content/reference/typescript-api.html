Every module of @lionlang/core is importable by path, such as @lionlang/core/evaluation/evaluate. These are the exports meant for host applications. Evaluation results are Effects; see Run Lion from TypeScript.

@lionlang/core/evaluation/evaluate

run(expression, environment, options?)

Decodes expression as a Lion program and evaluates it with environment, a record of bindings. Returns an Effect of the result, failing with a Lion error.

options.database: a LogicDatabase to use instead of an empty one. Its relations are bound by name, unless environment binds the same name.

evaluate(expression)

Evaluates an already decoded expression. Requires LionEnvironmentService and, for logic forms, LionDatabaseService. Most hosts use run.

@lionlang/core/modules

stdlib

The standard library as a record of bindings.

namespaceEntries(namespace, record)

Returns a copy of record with every key prefixed by namespace/.

@lionlang/core/logic/database

new LogicDatabase(options?)

A logic database to share across runs. It holds relations, schemas, facts, rules, and invariants.

options.goalDirected: when false, every query derives every row of the relations it reads instead of only what it can reach. Defaults to true.

@lionlang/core/logic/fit

fits(schema, value)

An Effect that gives whether a value fits a schema. A host function that takes a schema can check values with it. Like call, it needs what an evaluation provides.

problemsOf(schema, value)

An Effect that gives every place where the value does not fit, as schema/problems does.

misfit(schema, value)

An Effect that gives the sentence schema/assert fails with, or undefined when the value fits.

@lionlang/core/logic/model

MAX_LATTICE_ROUNDS

10,000: the rounds recursion through lattice aggregates may take before failing.

@lionlang/core/evaluation/special-forms/function

call(fn, ...args)

Calls a Lion function, such as a lambda a host function was given, and returns an Effect of its value. A goal the function returns is asked, so the value is true or false. If the value is not known yet, the Effect fails with WaitingError and the call the host function is part of waits. Use it in a host function that works with what its callback returns.

apply(fn, args)

Calls a function the way a Lion call does, and returns an Effect of what the call evaluates to, which can be a value that waits.

@lionlang/core/logic/snapshot

saveDatabase(database, options?)

Returns an Effect of the database as a snapshot program. Fails with LogicError if a rule or invariant holds a value with no written form: a lambda that calls itself, or a function the environment does not name.

options.isBound(name): names bound where the snapshot will be loaded; strings equal to them are quoted.

loadDatabase(program, environment)

Evaluates program into a new LogicDatabase and returns an Effect of it.

@lionlang/core/logic/algorithms

defineAlgorithm({ name, inputs, columns, run })

Returns a function to bind under name. Called in Lion with its inputs and one term per column, it builds a goal over the rows run computes.

  • inputs: a list of { kind: "relation" | "value", name }. A relation input is given as a relation's name or value; a value input as JSON data, or as a logic variable that another goal binds.
  • columns: the output column names.
  • run(inputs): receives each relation input as its list of tuples and each value input as itself. Returns a list of rows, each with one value per column, or a string that explains why it cannot. It runs once for each combination of input values a goal asks about.

@lionlang/core/logic/terms

logicFunction(fn)

Marks a function that takes logic variables as they are, and returns it. Every other function waits when it is called with a logic variable, so mark a function only when it builds a goal from the variables it is given, as a relation does.

new LogicForm(name, parts)

A logic form, held the way it is written: new LogicForm("=", [left, right]) is the goal ["=", left, right] makes, for a logic function to return. The names are "not", "and", "or", "=", "in", "find", and "schema/fits?". A relation call is an Atom, of the same module.

builtBy(fn, by, args)

Records that calling by with args built fn, and returns fn. The function is then written as that call, in messages and snapshots, as the functions that func/partial and the schema module make are.

readsOnlyArguments(bindings)

Marks the functions among the values of a record as reading nothing but their arguments, as every function of the standard library does. Lion cannot see what any other host function reads, so an invariant that calls one is asked in full after every change to facts. Marking a function lets such an invariant be asked only about what a change can have broken.

render(value)

Converts logic values, such as goals and variables, back into the Lion JSON that produces them.

compareValues(a, b)

The value order Lion sorts by: negative, zero, or positive.

@lionlang/core/analysis/analyze

analyze(expression)

Returns a tree describing each part of a program without evaluating it: its kind, its special form, the role of each child, and a diagnostic for a malformed form. The graph editor is built on it.

flattenAnalysis(node)

The nodes of an analysis tree, in order.

isSpecialFormName(value)

Whether value names a special or logic form.

@lionlang/core/errors/evaluation

ArgumentMismatchError, InvalidFunctionCallError, LogicError, and WaitingError, the tagged error classes described in Errors.

Services

LionEnvironmentService (@lionlang/core/services/evaluation) and LionDatabaseService (@lionlang/core/services/database) carry the environment and database through evaluation. run provides both. LionAskerService (@lionlang/core/services/asker) says who answers questions at the moment: evaluation sets it while a rule is being written and while one runs.

@lionlang/typesafe-ai

makeTypeSafeBindings(config?, namespace?)

Returns bindings to spread into an environment: noul, choice, score, system-one, and models, under namespace/, "typesafe" by default. config is the TypeSafe client configuration. See Ask AI models with TypeSafe.

makeTypeSafeModule(config?)

The same functions without a namespace.
