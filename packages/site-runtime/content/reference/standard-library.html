The default environment, stdlib, names each function module/function. Functions check their arguments and fail with SchemaError when one has the wrong type. Each takes a set number of arguments, and a call with any other number fails and says how many the function takes, as in "number/subtract" takes 2 arguments but got 3. Each module's example below calls every function in the module.

Every function waits when it is called with a logic variable among its arguments, so all of them work as filters and computed values in rules and queries. A function that is given a goal gets its answer, true or false; see Asking questions. Functions of the aggregate and graph modules take logic variables as they are, to build aggregates and goals.
