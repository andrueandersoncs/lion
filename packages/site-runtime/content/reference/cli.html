Install with bun add --dev @lionlang/cli. The package provides the lion command.

lion <file>

lion [--database <path>] <file>

Reads file as JSON, evaluates it with the standard library, and prints the result as JSON indented by two spaces.

Argument or flagMeaning
filePath to a Lion program in JSON. Required.
--database <path>A JSON file that holds the logic database. It is loaded before the program runs; if it does not exist, the database starts empty. After the program succeeds, the database is saved back as a snapshot, one form and one fact per line. If the program fails, the file is not written.

lion repl

lion repl [--host <address>] [--port <number>]

Serves the Fold Map graph editor bundled with the command, and prints its address. It runs until stopped.

FlagDefaultMeaning
--host127.0.0.1Address to listen on.
--port3000Port to listen on, from 1 to 65535.

Global flags

FlagMeaning
--help, -hShow help for the command or subcommand.
--version, -vShow the version.
--wizardBuild the command interactively.
--completions <shell>Print a completion script for bash, zsh, fish, powershell, sh, or pwsh.
--log-level <level>Minimum log level: all, trace, debug, info, warn, error, fatal, or none.

Exit status

0 when the program succeeds. 1 when the file cannot be read or parsed, the program fails, or the database cannot be loaded or saved; the error is printed.
