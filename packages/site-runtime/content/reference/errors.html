A failed evaluation is a typed Effect failure. Each error has a _tag you can catch with Effect.catchTag. On this page and in the editor, failures show as Tag: message.

TagRaised when
SchemaErrorThe program is not a valid Lion expression, such as a record key __proto__; a function receives an argument of the wrong type; or eval is given something that is not JSON.
UnboundNameErrorA string of the form module/name is evaluated, nothing is bound to it, and it reads as a misspelled name: other names of its module are bound, or a bound name is a letter or two away, which the message suggests. Inside quote the string is data.
InvalidFunctionCallErrorAn array's first element does not evaluate to a function, including a misspelled function name and a form's name used with the wrong shape.
ArgumentMismatchErrorA lambda is called with fewer arguments than it has parameters.
ArithmeticErrorArithmetic has no finite result, such as division by zero or an overflow. JSON cannot hold Infinity or NaN.
LogicErrorA logic form fails: an unsafe goal or rule, a recursion or question that breaks the rules, a broken invariant or query assertion, a key conflict, a bad option, and more. The message says what and where.
WaitingErrorA value was needed before it is known. A host function gets this error from call when a Lion function's value is not known yet; the call the host function is part of then waits, so a program does not see it. A program sees it when a fact, retract, or why written inside a rule, query, or find is given a question: those forms act right away, so they cannot wait.
NotAnObjectErrorA function that reads keys received something that is not an object, or a method function received null.
KeyNotFoundErrorobject/get-path reached a key that is not there.
IndexOutOfBoundsErrorobject/get-path indexed past the end of a list.
NotAnArrayErrorobject/get-path used a numeric segment on something that is not a list.
PathTraversalErrorA path passed through a value that is not an object before its last key, or a key that is not there.
InvalidPathErrorA path argument is not a string.
NotAFunctionErrorobject/call-method or object/get-method named something that is not a method.
MethodNotFoundErrorThe end of a method path is not a method.
EmptyPathErrorA method path is empty.
NotAConstructorErrorobject/new was given something that is not a class.

Examples

["number/add", "one", 2] ["number/plus", 1, 2] ["number/multiply", 1e308, 10] [["lambda", ["a", "b"], "a"], 1] ["begin", ["relation", "edge", ["from", "to"]], ["relation", "lonely", ["node"]], ["rule", ["lonely", "?n"], ["not", ["edge", "?n", "?_"]]]] ["object/get-path", ["quote", {"a": {"b": 1}}], "a.c"]

Errors inside rules and queries

A function that fails while a rule or query runs it fails the rule or query. The failure is a LogicError that names the call and the values it ran on. An ArithmeticError stays as it is, since it already names both. A filter that is not true or false, and an answer that is not JSON data, fail with a LogicError too.

["begin", ["relation", "reading", ["value"]], ["fact", ["reading", 4], ["reading", "n/a"]], ["query", ["and", ["reading", "?v"], ["number/greaterThan", "?v", 3]]]]

Errors from host functions

A host function that returns a failed Effect fails the program with that Effect's error. A host function that throws, or a defect inside the evaluator, fails the program as a defect rather than a typed error; Effect.runPromise rejects with it.
