This guide shows how to work with JavaScript values that your host puts in the environment, using the object and func modules.

Read values

object/get reads one key; object/get-path follows a dot path, with numbers for list positions:

["begin", ["define", "config", ["quote", {"users": [{"name": "ana"}, {"name": "bo"}], "port": 8080}]], {"port": ["object/get", "config", "port"], "second": ["object/get-path", "config", "users.1.name"], "keys": ["object/keys", "config"]}]

A record in a program evaluates its values, and a list inside it would be a call, so the data here is quoted.

Call a method

object/call-method calls a method by name with this set to the value. Every method function works on any value except null, including strings and lists:

{"upper": ["object/call-method", "lion", "toUpperCase"], "padded": ["object/call-method", "7", "padStart", 3, "0"], "joined": ["object/call-method", ["array/make", "a", "b"], "join", "-"]}

object/call-method-path follows a dot path through objects and calls the method at its end, such as "console.log" on a host value or "user.name.trim" on a record.

Construct an instance

When the host binds a class, object/new constructs it:

const env = { ...stdlib, URL }; await Effect.runPromise(run( ["object/get", ["object/new", "URL", "https://lionlang.dev/docs"], "pathname"], env)); // => "/docs"

Pass a Lion function to JavaScript

Lion functions return Effects, which JavaScript callbacks cannot use. func/callback wraps a Lion function so JavaScript can call it: the result comes back as a value, or as a Promise when the function's work is asynchronous. It keeps the relations and names of the program that created it.

["object/call-method", "button", "addEventListener", "click", ["func/callback", ["lambda", ["event"], ["console/log", "clicked"]]]]

Prepare functions in advance

["begin", ["define", "addTax", ["func/partial", "number/multiply", 1.25]], ["array/map", ["array/make", 10, 20], "addTax"]]

func/bind fixes this and leading arguments, and func/apply calls a function with a given this and arguments.
