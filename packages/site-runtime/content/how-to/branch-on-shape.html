This guide shows how to pick a branch based on what a value is. Use match when the choice depends on the value's type or structure, and cond when it depends on conditions you compute.

Branch on a value's type

Give match the value, then pairs of a predicate and a function, then a fallback function. The first predicate that returns true picks its function, which receives the value:

["begin", ["define", "describe", ["lambda", ["value"], ["match", "value", ["value/number?", ["lambda", ["n"], "a number"]], ["value/string?", ["lambda", ["s"], ["string/concat", "a string: ", "s"]]], ["value/array?", ["lambda", ["xs"], "a list"]], ["lambda", ["other"], "something else"]]]], ["array/map", ["quote", [7, "hi", [1, 2], null]], "describe"]]

Branch on a record's structure

A record can be a predicate too. It matches a record that has every one of its keys, where each value passes the predicate under that key. Records nest:

["begin", ["define", "route", ["lambda", ["message"], ["match", "message", [{"type": ["func/partial", "string/equals?", "order"], "order": {"id": "value/number?"}}, ["lambda", ["m"], ["object/get-path", "m", "order.id"]]], [{"type": ["func/partial", "string/equals?", "ping"]}, ["lambda", ["m"], "pong"]], ["lambda", ["m"], "unknown message"]]]], ["array/map", ["quote", [ {"type": "order", "order": {"id": 42}}, {"type": "ping"}, {"type": "order", "order": {"id": "x"}}]], "route"]]

A predicate that fails, or returns something other than a boolean, counts as no match, so a pattern never crashes on data of the wrong type.

Branch on computed conditions

When the choice depends on comparisons, list condition and result pairs in cond, with an optional else at the end:

["begin", ["define", "grade", ["lambda", ["score"], ["cond", [["number/greaterThanOrEqualTo", "score", 90], "A"], [["number/greaterThanOrEqualTo", "score", 75], "B"], ["else", "C"]]]], ["array/map", ["array/make", 95, 80, 40], "grade"]]

Without an else, a cond with no matching condition returns null. Conditions use JavaScript truthiness: false, null, 0, and "" do not match, and every list and record does.
