This guide shows how to use the lion command from @lionlang/cli.

Install the command

bun add --dev @lionlang/cli

In a project, run it with bun run lion. Installed globally, it is just lion.

Evaluate a file, inline expression, or standard input

Pass a JSON file, pass --eval (-e) for a quick one-liner, or pipe JSON into standard input (explicitly with - or implicitly when piped). Inject top-level JSON inputs with repeatable --bind (-b) or --bind-file flags, keeping exact numbers intact:

bun run lion add.json bun run lion -e '["number/add", 1, 2]' bun run lion -b tax=0.07 --bind-file order=order.json price.json echo '["number/add", 1, 2]' | bun run lion -

If the input is not valid JSON, or the program fails, lion prints the error and exits with status 1.

Check a program without running it

lion check reports malformed forms, misspelled names, wrong-arity calls, invalid relation/query/invariant options, unsafe rule heads or find templates, logic variables in ground facts, unreachable or non-exhaustive match cases, unreachable cond branches after else, duplicate lambda parameters, near-miss bare call heads, and Lion lints with JSON pointers. Pass --database or --bind/--bind-file to validate against external relations, schemas, and inputs read-only:

bun run lion check program.json bun run lion check --database store.json -e '["query", ["edge", "a", "?to"]]' bun run lion check --bind-file order=order.json price.json

Keep a logic database in a file

Add --database with a path. The file is loaded before the program runs and saved after it succeeds, so relations, facts, rules, and invariants carry over to the next run:

bun run lion setup.json --database store.json bun run lion more-facts.json --database store.json
  • A database file that does not exist yet starts empty.
  • The file is a snapshot: an ordinary Lion program, one form and one fact per line, so it diffs well in version control.
  • If the program fails, for example because it would break an invariant, the file is left as it was.
  • Running the same setup again keeps one copy of each rule and invariant.

Open the graph editor

bun run lion repl bun run lion repl --host 0.0.0.0 --port 8080

The editor listens on 127.0.0.1:3000 unless you pass --host or --port. Open the address it prints, then open a .json program.
