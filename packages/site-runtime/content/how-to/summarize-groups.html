This guide shows how to compute totals per group with aggregates in a rule's head.

Group and total

Put an aggregate such as ["aggregate/sum", "?amount"] in a column of the head. The head's other columns are the group:

["begin", ["relation", "order", ["id", "customer", "amount"]], ["relation", "spend", ["customer", "total", "orders"]], ["fact", ["order", 1, "ana", 30], ["order", 2, "ana", 20], ["order", 3, "bo", 50]], ["rule", ["spend", "?c", ["aggregate/sum", "?amount"], ["aggregate/count", "?id"]], ["order", "?id", "?c", "?amount"]], ["query", ["spend", "?customer", "?total", "?orders"], {"order": "customer"}]]

A group only exists when something matches, so a count is never 0. To report zeros, combine the aggregate with not in a second rule. The argument can also be a constant: ["aggregate/count", 1] counts the matches.

Pick the aggregate you need

["begin", ["relation", "reading", ["sensor", "n", "value"]], ["relation", "stats", ["sensor", "count", "unique", "sum", "mean", "min", "max", "values", "distinct"]], ["fact", ["reading", "s1", 1, 3], ["reading", "s1", 2, 5], ["reading", "s1", 3, 3], ["reading", "s2", 1, 9]], ["rule", ["stats", "?s", ["aggregate/count", "?v"], ["aggregate/countUnique", "?v"], ["aggregate/sum", "?v"], ["aggregate/mean", "?v"], ["aggregate/min", "?v"], ["aggregate/max", "?v"], ["aggregate/collect", "?v"], ["aggregate/unique", "?v"]], ["reading", "?s", "?_", "?v"]], ["query", ["stats", "?sensor", "?count", "?unique", "?sum", "?mean", "?min", "?max", "?values", "?distinct"], {"order": "sensor"}]]

Each reading has a number, n. Facts are a set, so without it the two readings of 3 from s1 would be a single fact and would count once. Every match of a rule's body counts once, so give repeated values something that tells them apart.

Aggregate computed values

An aggregate can combine a computed value:

["begin", ["relation", "line", ["order", "price", "quantity"]], ["relation", "total", ["order", "amount"]], ["fact", ["line", 1, 10, 3], ["line", 1, 5, 2], ["line", 2, 8, 1]], ["rule", ["total", "?o", ["aggregate/sum", ["number/multiply", "?price", "?quantity"]]], ["line", "?o", "?price", "?quantity"]], ["query", ["total", "?order", "?amount"], {"order": "order"}]]

Summarize each fact's own list

An aggregate call combines a rule's matches only as a whole argument of the head. Anywhere else, in a body or inside another call, it combines the list it is given, once for each match:

["begin", ["relation", "cart", ["id", "prices", "shipping"]], ["relation", "due", ["id", "amount"]], ["fact", ["cart", 1, ["array/make", 10, 5], 4], ["cart", 2, ["array/make", 8], 0]], ["rule", ["due", "?id", ["number/add", ["aggregate/sum", "?prices"], "?shipping"]], ["cart", "?id", "?prices", "?shipping"]], ["query", ["due", "?id", "?amount"], {"order": "id"}]]

Summarize a plain list

Outside a rule, every aggregate function combines a list right away:

{"sum": ["aggregate/sum", ["array/make", 3, 1, 3]], "mean": ["aggregate/mean", ["array/make", 3, 1, 3]], "unique": ["aggregate/unique", ["array/make", 3, 1, 3]]}
