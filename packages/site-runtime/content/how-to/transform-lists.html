This guide shows how to work with lists using the array module and lambdas.

Make a list

An array in a program is a call, so [1, 2, 3] on its own fails: 1 is not a function. Make a list with array/make, which evaluates its arguments, or with quote, which takes the list as written:

{"made": ["array/make", 1, ["number/add", 1, 1], 3], "quoted": ["quote", [1, ["number/add", 1, 1], 3]], "range": ["array/range", 0, 5]}

Change every item

Pass a list and a function to array/map:

["array/map", ["array/range", 1, 6], ["lambda", ["n"], ["number/multiply", "n", "n"]]]

Keep some items

Pass a list and a predicate to array/filter. Its function gives true or false, as a condition does:

["array/filter", ["array/range", 1, 11], ["lambda", ["n"], ["number/greaterThan", "n", 6]]]

Reverse and sort

array/reverse puts items in reverse order. array/sort puts items in ascending canonical order, or stably sorts by a two-argument predicate that says when the first item comes before the second:

{"reversed": ["array/reverse", ["array/make", "a", "b", "c"]], "sorted": ["array/sort", ["array/make", 3, 1, 4, 1, 5]], "descending": ["array/sort", ["array/make", 3, 1, 4, 1, 5], "number/greaterThan"]}

Combine items into one value

array/reduce takes a list, a starting value, and a function of the running value and the next item:

["array/reduce", ["array/make", 3, 9, 4], 0, ["lambda", ["sum", "n"], ["number/add", "sum", "n"]]]

For sums, counts, and other common totals, the aggregate module is shorter: ["aggregate/sum", list].

Take lists apart

{"first": ["array/head", ["array/make", "a", "b", "c"]], "rest": ["array/tail", ["array/make", "a", "b", "c"]], "length": ["array/length", ["array/make", "a", "b", "c"]], "hasB": ["array/includes?", ["array/make", "a", "b", "c"], "b"], "joined": ["array/concat", ["array/make", 1], ["array/make", 2, 3]]}

An empty list has no first item and no rest, so array/head and array/tail fail on one, as Scheme's car and cdr do. Ask for its length first, or use array/slice, which gives what part there is:

["array/head", ["array/make"]] ["begin", ["define", "first", ["lambda", ["items", "otherwise"], ["cond", [["number/equals?", ["array/length", "items"], 0], "otherwise"], ["else", ["array/head", "items"]]]]], {"of a list": ["first", ["array/make", "a", "b"], "none"], "of an empty one": ["first", ["array/make"], "none"], "a slice": ["array/slice", ["array/make"], 0, 1]}]
