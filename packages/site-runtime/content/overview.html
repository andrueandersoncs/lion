Lion is a small Lisp whose programs are JSON. It evaluates on Effect, edits as a graph, runs from the command line, and includes a Datalog-style logic database.

These docs follow the Diátaxis framework. There are four kinds of documentation, each written for a different need, and they are kept apart so each one can do its own job. Tutorials teach and how-to guides direct; both are practical. Reference and explanation inform; both are theoretical.

Where to start

  • New to Lion? Take the tutorial Your first Lion program. It takes about ten minutes, and every step runs in your browser.
  • Have a job to do? Pick a how-to guide, such as Run Lion from TypeScript or Enforce rules on your data.
  • Need an exact answer? The reference describes every special form, logic form, standard library function, and command.
  • Wondering why Lion works the way it does? Start with Why programs are JSON.

Every example is live

A program with a result under it is a live example. Edit the program and it runs again; press ⌘/Ctrl + Enter to run it at once, or Reset to bring back the original.

["number/multiply", ["number/add", 1, 2], 4]

Examples run in your browser on the same evaluator as @lionlang/core. Each one starts from the standard library, a fresh environment, and an empty logic database, so examples never affect each other. The results printed on this page were computed by that evaluator when the docs were built.
