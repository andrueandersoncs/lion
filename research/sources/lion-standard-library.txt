schema
Checks values against schemas, and builds schemas out of others. Anything is a schema; see What fits a schema. The functions that check take the value first, then the schema. schema gives a schema a name.
FunctionReturns
["schema/fits?", value, schema]Whether the value fits the schema. With a logic variable in it, it is a goal that also binds the variables of the schema; see Patterns.
["schema/problems", value, schema]Every place where the value does not fit, in the order of their paths; an empty list when it fits. A problem is a record with a path, the keys and positions that lead to the part. A part with the wrong value has what was expected, a schema written as the expression that makes it, and what was found. A part that is missing has only expected, and a key the schema does not name has only found.
["schema/assert", value, schema]The value, when it fits. When it does not, fails with a message that says where. As a value in a rule or find, it fails the query that runs it.
["schema/anyOf", schema, ...]A schema that fits a value which fits at least one of the schemas. Of plain values it is a list of choices. It reports one problem, at the value that fits none.
["schema/allOf", schema, ...]A schema that fits a value which fits every one of the schemas. It reports the problems of each schema the value does not fit.
["schema/arrayOf", schema]A schema that fits a list whose every item fits the schema
["schema/recordOf", schema]A schema that fits a record whose every value fits the schema
["schema/optional", schema]As the schema of a record's key, lets the key be left out; a key that is there must fit. Anywhere else it is the schema itself.
["schema/open", record]A schema that fits a record which fits the record of schemas, or the named schema of one, whatever other keys it has
What the building functions return is a function: called with a value, it says whether the value fits. A snapshot writes it as the call that built it.
